# GeneMedi 产品映射表初稿设计

## 目标

为 `genemedi-net` 建立一份可由业务人员审核和维护的“产品线 + 具体产品页”两级映射表。它将把 GA4 着陆页与 GSC 规范页面归属到同一产品维度，为后续按“时间 × 产品”查看自然搜索、访问、互动和真实询盘建立稳定基础。

本次交付只创建本地可编辑 Excel 初稿；不新增实时 GA4/GSC 拉取、不访问官网数据库、不修改 GA4/GSC 配置，也不向飞书写入数据。

## 采用的方式

采用“规则优先、页面人工覆盖”的方式。

1. **产品线**是默认汇总层，例如业务产品类别。
2. **具体产品页**是下钻层；每个页面候选项可以被人工指派到某一产品线和具体产品。
3. **映射规则**用于稳定覆盖同类 URL 路径；规则优先级低于人工页面覆盖，避免规则覆盖已经审核过的业务判断。
4. 页面不能可靠判定为产品时，保留为 `content`、`site` 或 `unclassified`，而不是猜测产品归属。

该方式比“逐页硬编码”更可维护，也比“只按路径自动分类”更可审计。

## 输入与边界

初稿使用已经生成的本地周报工作簿中的 `GA4 Pages` 与 `GSC Pages` 明细。页面路径仅被当作不可信文本进行清洗、去除查询参数和分组；不会被打开或执行。

候选页会按近期 GA4 sessions、GSC clicks 和 GSC impressions 排序，以便先审核对流量影响最大的页面。初稿不是完整产品目录，也不把未审核的猜测当成最终业务分类。

## 工作簿结构

### README

说明数据来源、日期范围、初稿生成规则、审核顺序，以及 GA4/GSC/真实询盘各自的口径边界。

### Product Lines

产品线的主数据表。业务人员可编辑产品线 ID、中文名称、英文名称、启用状态和审核备注。首版包含 `UNCLASSIFIED`、`CONTENT`、`SITE` 三个保留值，确保任何页面都有诚实的归属选项。

### Product Mapping

可编辑的映射规则表。每行包括：映射优先级、匹配方式、清洗后的路径规则、产品线 ID、产品 ID、页面类型、状态、审核人和备注。支持 `exact_path` 与 `path_prefix` 两种匹配方式。

### Priority Review

从 GA4 与 GSC 页面明细合并出的高优先级候选页。列出清洗后的路径、GA4 sessions、GSC clicks、GSC impressions、建议页面类型、建议产品线、审核状态和人工覆盖字段。该表用于第一轮审核，不会自动声称每一条都是产品页。

### All Page Candidates

保留全部合并后的候选页，供在需要时继续审核。它与 `Priority Review` 共享相同字段，但不替代产品目录。

### Value Lists

维护下拉选项，包括页面类型、审核状态、匹配方式和是否启用。编辑列将使用数据验证，降低拼写不一致造成的映射失败。

## 页面类型与审核状态

页面类型固定为：`product_detail`、`product_category`、`application`、`content`、`site`、`unclassified`。

审核状态固定为：`needs_review`、`approved`、`excluded`。只有 `approved` 的映射才应进入未来按产品汇总的正式报表；`excluded` 用于明确不纳入产品分析的内容或站点页。

## 真实询盘和 GA4 的关系

本地配置已列出 `inquiry` 与 `inquiry_success` 两个 GA4 关键事件。它们用于衡量前台表单提交信号；官网数据库中的 inquiry 记录是对真实询盘、产品、国家和处理状态的业务事实来源。

后续只能在“日期 × 产品”的聚合层比较二者，例如某产品线的 GA4 表单提交趋势与数据库真实询盘数。不得把个人信息、邮箱、姓名或数据库 inquiry ID 传入 GA4，也不得将 GA4 事件数直接当成唯一询盘人数。

## 飞书/Webhook 的后续接口

飞书多维表格或 Webhook 是交付目的地，不是本次映射表的来源。下一阶段将从已审核的产品映射和已聚合的统计结果产生固定字段，再采用幂等写入或 webhook 推送。字段将至少包括站点、统计周期、产品线、产品、GA4 指标、GSC 指标、真实询盘指标、数据新鲜度和生成时间。

## 验收标准

- 初稿为可编辑 `.xlsx`，各表结构清晰且冻结表头。
- 编辑列有明确标记与下拉验证；来源列与人工判断列分离。
- 候选页按流量优先级排列，保留未归类状态而不伪造产品归属。
- 工作簿通过关键范围检查、公式错误扫描和全表渲染预览。
- 无凭据、个人信息、数据库记录或外部写入。
